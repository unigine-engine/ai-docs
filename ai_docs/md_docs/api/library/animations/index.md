# Animations-Related Classes


UNIGINE provides two animation subsystems:


- **Timeline Animation** - the [Sequencer](../../../editor2/tools/sequencer/index.md), a keyframe system for animating anything the engine exposes over time: node transforms, material and property parameters, camera cuts, sound, events and the fields of your own components. One animation is one `*.seq` file, built out of [channels](../../../api/library/animations/timeline/class.animationchannel_cpp.md), and it is played either by the [NodeSequencePlayer](../../../api/library/nodes/class.nodesequenceplayer_cpp.md) node or by an [AnimationSequencePlayer](../../../api/library/animations/timeline/class.animationsequenceplayer_cpp.md) created from code.
- **Skeletal Animation** - a system for deforming skinned meshes through a skeleton (joint hierarchy). It includes skeleton and pose management, animation clip playback, animation graphs with blend trees and state machines, and retargeting between different skeletons.
