# InputModule::JoystickKeyBind Class

**Inherits from:** KeyBind


JoystickKeyBind extends **[KeyBind](../../../api/modules/input/class.keybind.md)** with joystick-specific features, including POV hat support. **POV** (Point of View) hats are digital directional inputs found on many flight sticks.


POV directions include UP, DOWN, LEFT, and RIGHT. Diagonal combinations are detected as co-directional with their components.
