# InputModule::JoystickAxisBind Class

**Inherits from:** AxisBind


JoystickAxisBind extends **[AxisBind](../../../api/modules/input/class.axisbind.md)** with joystick-specific features, including **POV**-based fake axes. This allows using POV hat directions as analog-like inputs.
