# InputModule::Mouse Class

**Inherits from:** Device


Mouse provides access to mouse input, including buttons and movement axes. Like the keyboard, the mouse is always considered valid.


Mouse axes include **MOUSE_AXIS_MOVE_X** (horizontal movement), **MOUSE_AXIS_MOVE_Y** (vertical movement), **MOUSE_AXIS_WHEEL_VERTICAL** (vertical scroll wheel), and **MOUSE_AXIS_WHEEL_HORIZONTAL** (horizontal scroll wheel).
