# WidgetVROptions Component

**Inherits from:** ComponentBase


WidgetVROptions provides a configuration **UI** for advanced **VR** features, particularly for **Varjo** headsets. The window includes controls for mixed reality, motion prediction, chromakey settings, depth testing, and camera parameters.


The component creates a window with grouped settings sections. For headsets that support mixed reality (video pass-through), it provides extensive controls for blending virtual and real content, including chromakey configuration for green screen setups.
