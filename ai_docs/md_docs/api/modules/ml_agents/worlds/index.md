# Unigine ML Integration Worlds


This section covers the components of the four worlds the demo ships with. They are not part of the framework: each one is an example of applying it to a task, and reading them side by side is the fastest way to see how the same base classes are put to different uses.


*Route Follow* is the simplest of the four - no sensors at all, a handful of numbers as the observation. *Line Follow* solves a task that can only be seen, steering from raw pixels. *Chase* pits two agents against each other where the target has to be found before it can be caught. *Soccer* trains two teams at once and takes a difficulty parameter from the trainer.
