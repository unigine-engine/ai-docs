# AirfieldLightsController Component

**Inherits from:** ComponentBase


A component that provides UI controls for managing airfield lighting systems. It creates a window with toggle buttons to control runway and taxiway lights through the **IG** (Image Generator) light controller.


The component allows toggling three light groups: runway lights (edge lights, touchdown zone lights, and centerline lights), approach lights (approach lighting system), and taxiway lights (edge lights and centerline lights).
