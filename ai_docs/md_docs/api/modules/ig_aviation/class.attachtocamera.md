# AttachToCamera Component

**Inherits from:** ComponentBase


AttachToCamera is a simple utility component that positions a node relative to the current camera every frame. This is useful for effects that should follow the camera view, such as HUD elements or camera-relative particle effects.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Settings Group |  |  |
| Offset | *Vec3* | Position offset from the camera. |
