# FieldHeigthParameterModifier Component

**Inherits from:** ComponentBase, ParameterModifier


FieldHeigthParameterModifier controls the power of a FieldHeight object based on a normalized value. FieldHeight objects modify terrain and landscape geometry, and this modifier allows dynamic control of the effect intensity.


This is useful for effects like rotor wash that push down grass or water based on helicopter proximity.
