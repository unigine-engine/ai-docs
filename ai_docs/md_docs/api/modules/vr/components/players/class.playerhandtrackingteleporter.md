# PlayerHandTrackingTeleporter Class

**Inherits from:** PlayerTeleporter


PlayerHandTrackingTeleporter implements teleportation for hand tracking systems. It extends **[PlayerTeleporter](../../../../../api/modules/vr/components/players/class.playerteleporter.md)** to handle gesture-based teleportation activation.


The teleporter uses hand tracking to detect pointing gestures and find valid teleport destinations. It is automatically integrated with **[VRHandTracking](../../../../../api/modules/vr/components/players/class.vrhandtracking.md)**.
