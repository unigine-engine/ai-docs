# ProgressObject Class


ProgressObject is an abstract interface for objects that report progress. Classes implementing this interface can be queried for their current progress state, typically used for handles, sliders, and other interactive controls.

## getProgress ( )

Returns the current progress value of the object.
### Return value

Progress value, typically in range [0.0; 1.0].
