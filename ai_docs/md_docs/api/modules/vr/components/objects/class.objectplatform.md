# ObjectPlatform Component

**Inherits from:** ComponentBase


ObjectPlatform marks a node as a moving platform that the player can stand on. When the player is on a platform, their movement is adjusted to account for the platform's velocity.


Add this component to moving floors, elevators, or vehicles that the player should move with.
