# WidgetSensorConfigurator Component

**Inherits from:** ComponentBase


WidgetSensorConfigurator creates a debug UI window for managing sensors at runtime. It displays all registered sensors with controls to toggle their enabled and active states.


The configurator automatically updates when sensors are created or removed. Use this during development to test sensor effects without modifying code.
