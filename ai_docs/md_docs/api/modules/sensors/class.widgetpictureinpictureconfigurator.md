# WidgetPictureInPictureConfigurator Component

**Inherits from:** ComponentBase


WidgetPictureInPictureConfigurator provides runtime controls for adjusting a WidgetPictureInPicture instance. It creates a configuration window with position presets.


Link this component to a **[WidgetPictureInPicture](../../../api/modules/sensors/class.widgetpictureinpicture.md)** node to enable user-controllable positioning of the overlay.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Picture In Picture | *Node* | Reference to the node containing the **[WidgetPictureInPicture](../../../api/modules/sensors/class.widgetpictureinpicture.md)** component. |
| Position | *Switch* | Position preset: Bottom Left, Bottom Right, or Bottom Center. |
