# KeyBindWidget Class

**Inherits from:** BindWidget


KeyBindWidget provides UI for configuring key/button bindings. It displays controls for all KeySettings options including direct key binding, axis-as-button, and POV directions.


The widget supports detection for key/button (press any key or button to assign) and axis for axis-as-button mode (move an axis past threshold).


Additional controls include use axis toggle to treat an analog axis as a button, axis invert checkbox, axis threshold slider, use **POV** toggle for joysticks, and a live key state indicator.
