# AxisBindWidget Class

**Inherits from:** BindWidget


AxisBindWidget provides UI for configuring axis bindings. It displays controls for all AxisSettings options including hardware axes, fake axes from keys, dead zones, sensitivity, and gravity.


The widget supports detection for hardware axis (move an analog stick/trigger to assign), positive key (press a key for the positive direction), and negative key (press a key for the negative direction).


Additional controls include axis clamp mode selector, invert checkbox, use fake axis toggle, use **POV** toggle for joysticks, dead zone slider, sensitivity and gravity sliders for fake axes, and a live axis state preview.
