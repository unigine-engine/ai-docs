# AFCS Component

**Inherits from:** ComponentBase


AFCS (Automatic Flight Control System) provides a UI panel for helicopter autopilot controls. It displays buttons for SAS (Stability Augmentation System) and altitude hold functions, interfacing with **[FlightLogic](../../../api/templates/template_aviation_rotarywing/class.flightlogic.md)** to toggle these features.


The panel renders as a widget with a configurable background texture and button positions.
