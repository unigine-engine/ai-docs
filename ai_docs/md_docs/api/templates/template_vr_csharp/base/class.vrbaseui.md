# VRBaseUI Component

**Inherits from:** Component


VRBaseUI is the base class for in-world GUI components. It initializes an ObjectGui or ObjectGuiMesh on the owner node and calls the virtual InitGui() method where derived classes create their widgets.


The component configures the GUI with virtual mouse mode and no background by default.
