# TooltipTextSwitcher Component

**Inherits from:** Component


TooltipTextSwitcher automatically switches the text of a **[VRTooltip](../../../../api/templates/template_vr_csharp/ui/class.vrtooltip.md)** based on the current input mode (PC or VR).


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Tooltip | *VRTooltip* | Target tooltip component. |
| PC Text | *String* | Text displayed when in PC input mode. |
| VR Text | *String* | Text displayed when in VR input mode. |
