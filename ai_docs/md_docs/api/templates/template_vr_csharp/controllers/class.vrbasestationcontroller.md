# VRBasestationController Component

**Inherits from:** BasestationController


VRBasestationController extends **[BasestationController](../../../../api/templates/template_vr_csharp/controllers/class.basestationcontroller.md)** to render and track physical VR base stations. It loads the base station 3D model from the VR runtime and updates its transform each frame. Activates only in VR input mode.
