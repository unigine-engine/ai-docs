# VRHandTracking Component

**Inherits from:** HandController


VRHandTracking extends **[HandController](../../../../api/templates/template_vr_csharp/controllers/class.handcontroller.md)** to provide skeletal hand tracking in VR mode. It maps VR hand bones to a skinned mesh and updates bone transforms each frame. Supports both OpenXR bone naming and custom bone name mapping. Activates only when VR hand tracking is available and the current input configuration is set to VR input.
