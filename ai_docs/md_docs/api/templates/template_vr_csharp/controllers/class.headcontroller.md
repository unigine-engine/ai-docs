# HeadController Component

**Inherits from:** VRBaseController


HeadController extends **[VRBaseController](../../../../api/templates/template_vr_csharp/base/class.vrbasecontroller.md)** to track the head-mounted display. It updates the node's world transform each frame based on the VR player's position and the HMD tracking data.
