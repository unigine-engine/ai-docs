# PCHeadController Component

**Inherits from:** HeadController


PCHeadController extends **[HeadController](../../../../api/templates/template_vr_csharp/controllers/class.headcontroller.md)** to provide head tracking in PC (non-VR) mode. It activates only when the current input configuration is set to PC input.
