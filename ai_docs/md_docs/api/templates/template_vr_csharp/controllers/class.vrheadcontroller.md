# VRHeadController Component

**Inherits from:** HeadController


VRHeadController extends **[HeadController](../../../../api/templates/template_vr_csharp/controllers/class.headcontroller.md)** to provide head tracking in VR mode. It activates only when the current input configuration is set to VR input and the VR system is loaded.
