# BasestationController Component

**Inherits from:** VRBaseController


BasestationController extends **[VRBaseController](../../../../api/templates/template_vr_csharp/base/class.vrbasecontroller.md)** to track a VR base station. It updates the node's world transform each frame based on the VR player's position and the base station tracking data.
