# SignalLinkOneToMany Component

**Inherits from:** Component


SignalLinkOneToMany connects one signal emitter to multiple signal slots. Automatically subscribes slot components to the emitter's signal events on initialization.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Emitter | *Node* | Node containing an ISignalEmitter component. |
| Slots | *Node[]* | Array of nodes containing ISignalSlot components. |
