# SoundManager Component

**Inherits from:** Component


SoundManager provides static methods for playing one-shot and looping 3D sounds at specified world positions.


## SoundManager Class

---

## static void PlaySound ( )

Plays a one-shot 3D sound at the specified position.
### Arguments

## static void PlayLoopSound ( )

Plays a looping 3D sound at the specified position for the given duration.
