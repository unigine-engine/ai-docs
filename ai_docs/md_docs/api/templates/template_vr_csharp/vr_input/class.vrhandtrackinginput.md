# VRHandTrackingInput Component

**Inherits from:** VRBaseControllerInput


VRHandTrackingInput extends **[VRBaseControllerInput](../../../../api/templates/template_vr_csharp/base/class.vrbasecontrollerinput.md)** to provide controller input through hand tracking gestures. Maps hand gestures (pinch, grab, wrist hold) to abstract controller buttons and axes.
