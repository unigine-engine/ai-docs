# VRControllerInput Component

**Inherits from:** VRBaseControllerInput


VRControllerInput extends **[VRBaseControllerInput](../../../../api/templates/template_vr_csharp/base/class.vrbasecontrollerinput.md)** to map physical VR controller buttons and axes to abstract controller input. Each button and axis can be configured with custom VR button bindings in the editor.
