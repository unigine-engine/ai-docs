# VRGeneralInput Component

**Inherits from:** VRBaseGeneralInput


VRGeneralInput extends **[VRBaseGeneralInput](../../../../api/templates/template_vr_csharp/base/class.vrbasegeneralinput.md)** to map physical VR controller buttons and axes to abstract general input. Each button and axis can be configured with custom VR controller bindings in the editor.
