# PCGeneralInput Component

**Inherits from:** VRBaseGeneralInput


PCGeneralInput extends **[VRBaseGeneralInput](../../../../api/templates/template_vr_csharp/base/class.vrbasegeneralinput.md)** to map keyboard and mouse input to abstract general buttons and axes in PC mode. Each button and axis can be configured with custom key/mouse bindings in the editor.
