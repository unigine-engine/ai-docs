# HeadCollision Class


HeadCollision is a standalone (non-component) utility class that detects collisions between the VR player's head and obstacle geometry. Used by **[VRMovementManager](../../../../api/templates/template_vr_csharp/movements/class.vrmovementmanager.md)** to prevent the player from clipping through walls.


## HeadCollision Class

---

## void Init ( )

Initializes the head collision system with the given obstacle geometry and trigger scale.
### Arguments

## void Update ( )

Updates the head collision detection and adjusts the virtual-to-real offset to prevent clipping.
