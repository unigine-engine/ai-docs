# WalkMovement Component

**Inherits from:** VRBaseMovement


WalkMovement extends **[VRBaseMovement](../../../../api/templates/template_vr_csharp/base/class.vrbasemovement.md)** to provide thumbstick-based walking in VR mode. Supports a dead zone and optional controller-relative movement direction.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Speed | *Float* | Movement speed. |
| Dead Zone | *Float* | Thumbstick dead zone threshold. |
| Use Controller Transform | *Bool* | Whether movement direction is relative to the controller instead of the head. |
