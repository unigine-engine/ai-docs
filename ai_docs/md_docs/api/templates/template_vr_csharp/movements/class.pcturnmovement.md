# PCTurnMovement Component

**Inherits from:** VRBaseMovement


PCTurnMovement extends **[VRBaseMovement](../../../../api/templates/template_vr_csharp/base/class.vrbasemovement.md)** to provide mouse-look turning in PC (non-VR) mode. Supports configurable mouse sensitivity and vertical angle limits.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Mouse Sensitivity | *Float* | Mouse look sensitivity. |
| Min Vertical Angle | *Float* | Minimum vertical look angle (degrees). |
| Max Vertical Angle | *Float* | Maximum vertical look angle (degrees). |
