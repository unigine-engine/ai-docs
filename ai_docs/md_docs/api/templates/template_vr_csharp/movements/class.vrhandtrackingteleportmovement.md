# VRHandTrackingTeleportMovement Component

**Inherits from:** TeleportationMovement


VRHandTrackingTeleportMovement extends **[TeleportationMovement](../../../../api/templates/template_vr_csharp/movements/class.teleportationmovement.md)** to provide teleportation using hand tracking gestures instead of controller thumbsticks. The teleport is triggered by a pinch gesture and the ray originates from the tracked hand position.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Side | *TELEPORT_SIDE* | Which hand is used for teleportation. |
