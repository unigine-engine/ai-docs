# VRLaserPointer Component

**Inherits from:** VRBaseInteractable


VRLaserPointer extends **[VRBaseInteractable](../../../../api/templates/template_vr_csharp/base/class.vrbaseinteractable.md)** to implement a grabbable laser pointer. When used, it projects a ray and displays a hit marker and distance text at the intersection point.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Laser | *Node* | Root node of the laser pointer assembly. |
| Laser Ray | *Node* | Node representing the visible laser ray. |
| Laser Hit | *Node* | Node placed at the laser hit point. |
| Object Text | *ObjectText* | Text object displaying the distance measurement. |
