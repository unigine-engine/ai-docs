# VRHandTrackingMenuInteraction Component

**Inherits from:** VRHandMenuInteraction


VRHandTrackingMenuInteraction extends **[VRHandMenuInteraction](../../../../api/templates/template_vr_csharp/interactions/class.vrhandmenuinteraction.md)** to provide ray-based interaction when using hand tracking instead of VR controllers. The ray originates from the tracked hand position.
