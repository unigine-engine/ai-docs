# Generator Component

**Inherits from:** Component


Generator is a signal-emitting component that monitors the connection state of two sockets and emits signal events based on whether both sockets have plugged-in objects. Implements the ISignalEmitter interface.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| First Socket | *Node* | First socket node to monitor. |
| Second Socket | *Node* | Second socket node to monitor. |
