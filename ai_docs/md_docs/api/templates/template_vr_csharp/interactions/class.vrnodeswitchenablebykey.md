# VRNodeSwitchEnableByKey Component

**Inherits from:** VRBaseInteractable


VRNodeSwitchEnableByKey extends **[VRBaseInteractable](../../../../api/templates/template_vr_csharp/base/class.vrbaseinteractable.md)** to toggle the enabled state of a set of nodes based on a button press while the object is grabbed.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Nodes To Switch | *Node[]* | Array of nodes whose enabled state will be toggled. |
| Default Nodes State | *NodeState* | Initial enabled state of the nodes (Enabled or Disabled). |
