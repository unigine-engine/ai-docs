# VRSocketObject Component

**Inherits from:** Component


VRSocketObject defines a socket point where **[VRPluggable](../../../../api/templates/template_vr_csharp/interactions/class.vrpluggable.md)** objects can be connected. Each socket has an integer ID used for compatibility matching. Provides a static initialization event and a transform for positioning plugged objects.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| ID | *Int* | Socket identifier used for plug compatibility matching. |
| Plugged Transform Node | *Node* | Node defining the transform where plugged objects are placed. |
