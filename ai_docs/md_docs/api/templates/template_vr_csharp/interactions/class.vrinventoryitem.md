# VRInventoryItem Component

**Inherits from:** Component


VRInventoryItem marks an object as storable in a **[VRInventory](../../../../api/templates/template_vr_csharp/interactions/class.vrinventory.md)**. Configures positional and rotational offsets for how the item appears when placed in the inventory grid.


### Component Parameters


| Name | Type | Description |
|---|---|---|
| Translation | *vec3* | Positional offset when displayed in the inventory. |
| Rotation | *vec3* | Rotational offset (Euler angles) when displayed in the inventory. |
