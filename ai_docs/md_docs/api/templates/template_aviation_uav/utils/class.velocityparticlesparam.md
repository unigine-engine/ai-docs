# VelocityParticlesParam Component

**Inherits from:** ComponentBase


VelocityParticlesParam automatically modifies connected ParameterModifier components based on the node's current velocity.


### Component Parameters


| Name | Type | Default | Description |
|---|---|---|---|
| Max Velocity | *Float* | *10.0* | Speed at which the parameter values will be set to 1. |
| Parameter Modifiers | *Node[]* | � | Array of nodes with [ParameterModifier](../../../../api/templates/template_aviation_uav/utils/class.parametermodifier.md) components. |
