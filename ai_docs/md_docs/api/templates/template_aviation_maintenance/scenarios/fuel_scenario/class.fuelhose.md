# FuelHose Component

**Inherits from:** VRObjectPhysicalCable


FuelHose extends **[VRObjectPhysicalCable](../../../../../api/modules/vr/components/objects/class.vrobjectphysicalcable.md)** to provide a physical fuel hose that connects the fuel station to the aircraft. The hose uses physics simulation to create realistic cable behavior.
