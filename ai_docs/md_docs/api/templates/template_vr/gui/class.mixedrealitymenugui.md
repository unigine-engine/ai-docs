# MixedRealityMenuGui Component

**Inherits from:** MenuBaseUI


MixedRealityMenuGui provides an in-world GUI menu for controlling mixed reality features on Varjo headsets. The menu is rendered on an ObjectGui and includes controls for mixed reality mode, motion prediction, chromakey settings, depth testing, camera parameters, and application rendering settings.


The component extends **[MenuBaseUI](../../../../api/modules/vr/components/objects/class.menubaseui.md)** and creates its GUI widgets dynamically in the init_gui() method.
