# HandMenuSampleGui Component

**Inherits from:** MenuBaseUI


HandMenuSampleGui is a sample hand-attached GUI menu that provides runtime controls for VR locomotion and hand tracking settings. It includes toggles for teleportation, joystick movement, and hand tracking mode switching (dynamic/static, controller/hand tracking).


The component extends **[MenuBaseUI](../../../../api/modules/vr/components/objects/class.menubaseui.md)** and creates its GUI widgets dynamically in the init_gui() method.
