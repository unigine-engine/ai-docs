# WorldMenuSampleGui Component

**Inherits from:** MenuBaseUI


WorldMenuSampleGui is a sample in-world GUI menu that demonstrates how to create a simple interactive menu rendered on an ObjectGui surface. It extends **[MenuBaseUI](../../../../api/modules/vr/components/objects/class.menubaseui.md)** and creates its GUI widgets dynamically.
