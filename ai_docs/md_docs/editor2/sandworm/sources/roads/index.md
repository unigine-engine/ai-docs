# Roads


Roads are generated by tiling a decal created from a *[Mesh Static](../../../../objects/objects/mesh/index.md)* object along the vector data available.


![](../../workflow/roads/example.jpg)


The object location and details are retrieved from vector data sources (`*.shp`, `*.geojson`, and `*.sxf` assets). If you have other types of files, you may try adding them as *External Files*. See the [list of supported formats](../../../../editor2/sandworm/index.md#data_formats).


Filter settings are described [here](../../../../editor2/sandworm/sources/index.md#filters).


An example of creating a road is given [here](../../../../editor2/sandworm/workflow/roads/index.md).


## Parameters


![Road object parameters](road_parameters.png)


| Node | The path to the primary object's `*.node` file. The object is created as *[Mesh Static](../../../../objects/objects/mesh/index.md)* and then [exported to a `.node` file](../../../../editor2/exporting_nodes/index.md#export_to_noderef). |
|---|---|
| Decal Texture Resolution | Resolution of the decal texture into which road projections are baked: from 128 to 16384, 1024 by default. |
| Split Segments | Flag indicating whether the segment splitting mode is enabled. In this mode, all line segments are divided into subsegments of the specified length (if this length does not exceed the length of the segment itself). This parameter can be used to provide smoother curving and better alignment of decals with the terrain. |
| Split Segment Length | Length of the subsegment for splitting mode, in units. > **Notice:** Splitting a segment into too many subsegments (i. e. using very small values) affects the generation time and memory consumption. > **Notice:** The parameter is shown only when *[Split Segments](#split_segments)* is enabled. |
| Split Lines Length (km) | Roads are projected onto a terrain using the Decal object. A decal object might be too big, and it is split into segments for optimization purposes. Splitting the lines implies forming a grid with a cell size defined by this Split Lines Length value and making the grid cells individual Decal objects. |
| Smooth Threshold | Flag indicating whether sharp corners of the road spline are preserved. When enabled, the segments whose angle exceeds the **[Smooth Threshold Angle](#smooth_threshold_angle)** are not smoothed. |
| Smooth Threshold Angle | Maximum angle between adjacent road segments, in degrees, that is still considered smooth. Segments with a larger angle are not smoothed. Available only when *[Smooth Threshold](#smooth_threshold)* is enabled. The default value is 100. |
| Adjust Terrain Heights and Masks | Flag indicating whether terrain heights and masks will be adjusted for generated roads. When this option is enabled, the following terrain data will be modified in the areas along the roads (vector data) having the width specified by the **[Area Width](#area_width)** parameter: - **Heightmap data** will be adjusted (flattened) to provide better alignment of generated roads with the terrain surface. ![](height_off.jpg) ![](height_on.jpg) - **Masks data** will be cut out (e.g. preventing grass from growing on roads). > **Notice:** Every mask layer in the project is cut out along the roads, not only the one used for vegetation. ![](masks_off.jpg) ![](masks_on.jpg) > **Notice:** - Enabling this option significantly increases generation time. > - Adjustment will affect all height and mask LODs of *Terrain Global* having the density satisfying the following condition: **Density < Area Width x 6**. |
| Area Width | Width of the area along the spline to be affected by heights and masks adjustment. > **Notice:** Has an effect only when *[Adjust Terrain Heights and Masks](#adjust_heights_masks)* is enabled. |
| Forward AXIS | Axis along which the primary mesh is to be extruded or tiled: X, -X, Y, -Y. |
| Spline Mode | Defines how the primary mesh is applied along the spline: - ***Stretch*** scales the mesh to the full length of the spline - ***Tiling*** repeats the mesh at its original size |
