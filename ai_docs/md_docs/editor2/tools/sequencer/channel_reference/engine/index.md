# Specific Engine Channels


These come from the *ENGINE PARAMETERS* half of the picker and are ordinary reflected parameters, keyed like any other. They are described here because reaching the one you want takes more than picking it from the menu: the parameter has to be addressed once the channel exists, by a path, a name or an index.


| [Property](../../../../../editor2/tools/sequencer/channel_reference/property/index.md) | A parameter inside a `*.prop`, addressed by its path. |
|---|---|
| [Render Parameters](../../../../../editor2/tools/sequencer/channel_reference/render_parameters/index.md) | A project-wide custom render parameter, addressed by name or by index. |
| [Animation Graph Parameters](../../../../../editor2/tools/sequencer/channel_reference/anim_graph_parameters/index.md) | A parameter exposed by an animation graph, steering it rather than overriding it. |


All three address something that exists in several copies, so the same rules apply as to any other slot. See [Parameter Slots](../../../../../editor2/tools/sequencer/channels/index.md#slots).
