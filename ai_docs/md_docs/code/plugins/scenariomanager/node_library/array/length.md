# Array Length


![](../img/array_length.png)

### Description

Outputs the number of elements in the array. An empty array gives 0.


Valid indices run from 0 to **Length** minus one.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/array.png) | **Array** | The array to measure. |
| ![](../img/types/int.png) | **Length** | The number of elements in the array. |
