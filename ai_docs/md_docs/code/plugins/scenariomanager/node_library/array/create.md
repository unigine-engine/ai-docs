# Array Create


![](../img/array_create.png)

### Description

Outputs a new empty array. Use it to initialize a variable that is filled later with [Array Append](../../../../../code/plugins/scenariomanager/node_library/array/append.md).


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/array.png) | **Array** | An array with no elements. |
