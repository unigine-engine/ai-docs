# Array Make


![](../img/array_make.png)

### Description

Builds an array from the values connected to its inputs, keeping them in top-to-bottom order.


The number of inputs is not fixed: add or remove input ports in the node body to collect as many values as needed. Inputs are of the Any type, so a single array can mix values of different types.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/any.png) | **Elem 0** | The first element. |
| ![](../img/types/any.png) | **Elem 1** | The second element. |
| ![](../img/types/array.png) | **Array** | The resulting array. |
