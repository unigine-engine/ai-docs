# To String


![](../img/to_string.png)

### Description

Converts a value to its text form.


The input port is shown as Float, but a value of any type may be connected to it - vectors, matrices and booleans are all converted to text.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/float.png) | **Value** | The value to convert. |
| ![](../img/types/string.png) | **Result** | The value as text. |
