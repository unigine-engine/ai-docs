# String to Int


![](../img/string_to_int.png)

### Description

Reads an integer out of a string.


A string that does not begin with a number gives 0.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/string.png) | **Value** | The string to read the number from. |
| ![](../img/types/int.png) | **Result** | The number read from the string. |
