# String Nodes


Nodes that build strings from values and read numbers back out of them.


To write a string to the console or the log rather than pass it on, use [Log](../../../../../code/plugins/scenariomanager/node_library/debug/log.md) or [Format Log](../../../../../code/plugins/scenariomanager/node_library/debug/flog.md), which format their message the same way.
