# String to Float


![](../img/string_to_float.png)

### Description

Reads a floating-point number out of a string.


A string that does not begin with a number gives 0.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/string.png) | **Value** | The string to read the number from. |
| ![](../img/types/float.png) | **Result** | The number read from the string. |
