# On Shutdown


![](../img/on_shutdown.png)

### Description

Fires once, when the script stops. Use it to clean up after a scenario - restoring what was changed, or reporting a result.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/exec.png) | **Event** | Fires once when the script stops. |
