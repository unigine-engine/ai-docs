# On Init


![](../img/on_init.png)

### Description

Fires once, when the script starts. Use it to set up the initial state of a scenario - filling variables, positioning objects, or starting other scripts.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/exec.png) | **Event** | Fires once at startup. |
