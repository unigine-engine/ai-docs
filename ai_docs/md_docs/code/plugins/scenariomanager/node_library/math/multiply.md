# Multiply


![](../img/multiply.png)

### Description

Multiplies **A** by **B**.


Numbers and vectors are both accepted. With vectors the operation is applied to each component separately, and a number combined with a vector is applied to every component of it.


Two vectors are multiplied component by component, which is neither a dot nor a cross product - see [Dot](../../../../../code/plugins/scenariomanager/node_library/vector/dot.md) and [Cross](../../../../../code/plugins/scenariomanager/node_library/vector/cross.md) for those.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/any.png) | **A** | The first operand. |
| ![](../img/types/any.png) | **B** | The second operand. |
| ![](../img/types/any.png) | **Result** | The result of the operation. |
