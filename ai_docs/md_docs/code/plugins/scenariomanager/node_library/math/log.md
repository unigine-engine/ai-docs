# Log


![](../img/log.png)

### Description

Outputs the natural logarithm of **A**.


Numbers and vectors are both accepted; with a vector the operation is applied to each component separately.


The result is always a real number. An input of zero gives negative infinity, and a negative input gives a value that is not a number.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/any.png) | **A** | The operand. |
| ![](../img/types/any.png) | **Result** | The result of the operation. |
