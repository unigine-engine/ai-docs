# Logic


Nodes that combine boolean values, so that several conditions can be weighed together before a decision is made.


## Unconnected Inputs


[ALL](../../../../../../code/plugins/scenariomanager/node_library/math/logic/all.md) and [ANY](../../../../../../code/plugins/scenariomanager/node_library/math/logic/any.md) take a variable number of inputs and ignore those left unconnected, which is what lets one node weigh however many conditions a graph happens to have without empty inputs affecting the result.
