# ANY


![](../../img/any.png)

### Description

Outputs true when at least one connected input is true.


The number of inputs is not fixed: add or remove input ports in the node body to test as many conditions as needed. Ports with nothing connected to them are ignored rather than counted as false.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/bool.png) | **In 0** | The first condition. |
| ![](../../img/types/bool.png) | **In 1** | The second condition. |
| ![](../../img/types/bool.png) | **Result** | The result of the comparison. |
