# OR


![](../../img/or.png)

### Description

Outputs true when at least one of **A** and **B** is true.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/bool.png) | **A** | The first operand. |
| ![](../../img/types/bool.png) | **B** | The second operand. |
| ![](../../img/types/bool.png) | **Result** | The result of the comparison. |
