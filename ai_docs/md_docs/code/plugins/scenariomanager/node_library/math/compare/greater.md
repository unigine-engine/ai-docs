# Greater


![](../../img/greater.png)

### Description

Outputs true when **A** is greater than **B**.


Only the first component is compared when a vector is connected. To compare whole vectors, use [Equal](../../../../../../code/plugins/scenariomanager/node_library/math/compare/equal.md), which checks every component.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/any.png) | **A** | The first operand. |
| ![](../../img/types/any.png) | **B** | The second operand. |
| ![](../../img/types/bool.png) | **Result** | The result of the comparison. |
