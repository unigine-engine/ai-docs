# Subtract


![](../img/subtract.png)

### Description

Subtracts **B** from **A**.


Numbers and vectors are both accepted. With vectors the operation is applied to each component separately, and a number combined with a vector is applied to every component of it.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/any.png) | **A** | The first operand. |
| ![](../img/types/any.png) | **B** | The second operand. |
| ![](../img/types/any.png) | **Result** | The result of the operation. |
