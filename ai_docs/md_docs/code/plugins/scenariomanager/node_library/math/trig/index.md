# Trig


Trigonometric nodes, used to convert between angles and the offsets or ratios they describe.


## Angles Are in Radians


These nodes measure angles in radians, unlike the rotation nodes of the [Quaternion](../../../../../../code/plugins/scenariomanager/node_library/quaternion/index.md) category, which work in degrees. Convert between the two with a [Multiply](../../../../../../code/plugins/scenariomanager/node_library/math/multiply.md) where a value crosses between them.


The single-input nodes always produce a real result, even from a whole input.
