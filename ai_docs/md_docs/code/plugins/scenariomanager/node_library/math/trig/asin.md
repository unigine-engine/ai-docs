# Asin


![](../../img/asin.png)

### Description

Outputs the angle whose sine is **A**.


Angles are measured in radians.


The input is clamped to the range from -1 to 1, so a value outside it gives the nearest valid angle rather than an error.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/any.png) | **A** | The operand. |
| ![](../../img/types/any.png) | **Result** | The result of the operation. |
