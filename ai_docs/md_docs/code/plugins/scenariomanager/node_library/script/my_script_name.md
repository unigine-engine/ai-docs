# Get My Script Name


![](../img/get_my_script_name.png)

### Description

Outputs the name of the script this node belongs to.


Unlike the identifier, the name is the same every time the graph runs, which makes it convenient as a tag in log entries.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/string.png) | **Name** | The name of the running script. |
