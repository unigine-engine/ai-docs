# Mat2 Identity


![](../img/mat2_identity.png)

### Description

Outputs a 2x2 identity matrix - the matrix that leaves a value unchanged when it is multiplied by it.


The node has no parameters. Use it as the starting point for building a transformation, or as a neutral value where a matrix is required.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/mat2.png) | **Value** | The identity matrix. |
