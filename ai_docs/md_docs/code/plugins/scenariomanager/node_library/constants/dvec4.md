# DVec4


![](../img/dvec4.png)

### Description

Outputs a four-component double-precision vector built from the **X**, **Y**, **Z** and **W** parameters typed into the node body.


Double precision keeps the value accurate over very large distances, which makes this type the one to use for world positions in a large scene.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/dvec4.png) | **Value** | The constant DVec4 value. |
