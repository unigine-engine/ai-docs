# IVec4


![](../img/ivec4.png)

### Description

Outputs a four-component integer vector built from the **X**, **Y**, **Z** and **W** parameters typed into the node body.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/ivec4.png) | **Value** | The constant IVec4 value. |
