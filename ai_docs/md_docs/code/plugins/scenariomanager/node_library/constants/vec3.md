# Vec3


![](../img/vec3.png)

### Description

Outputs a three-component vector built from the **X**, **Y** and **Z** parameters typed into the node body.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec3.png) | **Value** | The constant Vec3 value. |
