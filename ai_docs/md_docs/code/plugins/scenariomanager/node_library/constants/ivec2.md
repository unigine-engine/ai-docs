# IVec2


![](../img/ivec2.png)

### Description

Outputs a two-component integer vector built from the **X** and **Y** parameters typed into the node body.

| Name | Description |  |
|---|---|---|
| ![](../img/types/ivec2.png) | **Value** | The constant IVec2 value. |
