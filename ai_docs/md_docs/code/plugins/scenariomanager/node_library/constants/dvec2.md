# DVec2


![](../img/dvec2.png)

### Description

Outputs a two-component double-precision vector built from the **X** and **Y** parameters typed into the node body.


Double precision keeps the value accurate over very large distances, which makes this type the one to use for world positions in a large scene.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/dvec2.png) | **Value** | The constant DVec2 value. |
