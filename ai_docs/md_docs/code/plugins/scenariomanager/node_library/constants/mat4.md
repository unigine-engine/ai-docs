# Mat4 Identity


![](../img/mat4_identity.png)

### Description

Outputs a 4x4 identity matrix - the matrix that leaves a value unchanged when it is multiplied by it.


The node has no parameters. Use it as the starting point for building a transformation, or as a neutral value where a matrix is required.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/mat4.png) | **Value** | The identity matrix. |
