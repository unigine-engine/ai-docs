# DMat4 Identity


![](../img/dmat4_identity.png)

### Description

Outputs a 4x4 double-precision identity matrix - the matrix that leaves a value unchanged when it is multiplied by it.


The node has no parameters. Use it as the starting point for building a transformation, or as a neutral value where a matrix is required.


Double precision keeps the value accurate over very large distances, which makes this type the one to use for world positions in a large scene.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/dmat4.png) | **Value** | The identity matrix. |
