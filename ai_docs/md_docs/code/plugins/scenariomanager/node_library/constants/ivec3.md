# IVec3


![](../img/ivec3.png)

### Description

Outputs a three-component integer vector built from the **X**, **Y** and **Z** parameters typed into the node body.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/ivec3.png) | **Value** | The constant IVec3 value. |
