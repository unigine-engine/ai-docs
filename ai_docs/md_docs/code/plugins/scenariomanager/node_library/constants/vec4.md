# Vec4


![](../img/vec4.png)

### Description

Outputs a four-component vector built from the **X**, **Y**, **Z** and **W** parameters typed into the node body.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec4.png) | **Value** | The constant Vec4 value. |
