# Subgraph Output


![](../img/subgraph_output.png)

### Description

Declares one data pin that the graph returns, and takes the value to return. Each of these nodes becomes one output pin on the [Subgraph](../../../../../code/plugins/scenariomanager/node_library/subgraph/ref.md) node in the parent graph.


Where several outputs are declared, the order they are arranged in is the order the pins appear in on the parent side.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/any.png) | **Value** | The value to return to the parent graph. |
