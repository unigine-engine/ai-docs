# Break Vec3


![](../../img/break_vec3.png)

### Description

Splits a Vec3 into its 3 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec3.png) | **V** | The vector to split. |
| ![](../../img/types/float.png) | **X** | The X component. |
| ![](../../img/types/float.png) | **Y** | The Y component. |
| ![](../../img/types/float.png) | **Z** | The Z component. |
