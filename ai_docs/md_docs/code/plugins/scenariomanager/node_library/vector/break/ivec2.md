# Break IVec2


![](../../img/break_ivec2.png)

### Description

Splits an IVec2 into its 2 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec2.png) | **V** | The vector to split. |
| ![](../../img/types/int.png) | **X** | The X component. |
| ![](../../img/types/int.png) | **Y** | The Y component. |
