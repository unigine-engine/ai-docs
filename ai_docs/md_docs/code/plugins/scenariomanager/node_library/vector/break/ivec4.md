# Break IVec4


![](../../img/break_ivec4.png)

### Description

Splits an IVec4 into its 4 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec4.png) | **V** | The vector to split. |
| ![](../../img/types/int.png) | **X** | The X component. |
| ![](../../img/types/int.png) | **Y** | The Y component. |
| ![](../../img/types/int.png) | **Z** | The Z component. |
| ![](../../img/types/int.png) | **W** | The W component. |
