# Break Vec4


![](../../img/break_vec4.png)

### Description

Splits a Vec4 into its 4 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec4.png) | **V** | The vector to split. |
| ![](../../img/types/float.png) | **X** | The X component. |
| ![](../../img/types/float.png) | **Y** | The Y component. |
| ![](../../img/types/float.png) | **Z** | The Z component. |
| ![](../../img/types/float.png) | **W** | The W component. |
