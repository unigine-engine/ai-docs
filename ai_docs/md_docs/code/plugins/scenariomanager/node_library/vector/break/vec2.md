# Break Vec2


![](../../img/break_vec2.png)

### Description

Splits a Vec2 into its 2 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec2.png) | **V** | The vector to split. |
| ![](../../img/types/float.png) | **X** | The X component. |
| ![](../../img/types/float.png) | **Y** | The Y component. |
