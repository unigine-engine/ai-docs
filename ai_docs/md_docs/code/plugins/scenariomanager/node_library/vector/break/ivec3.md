# Break IVec3


![](../../img/break_ivec3.png)

### Description

Splits an IVec3 into its 3 components, so that each can be read or processed on its own.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec3.png) | **V** | The vector to split. |
| ![](../../img/types/int.png) | **X** | The X component. |
| ![](../../img/types/int.png) | **Y** | The Y component. |
| ![](../../img/types/int.png) | **Z** | The Z component. |
