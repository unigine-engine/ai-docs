# Break


Nodes that split a vector into its components, so that each can be read or processed on its own - taking the height out of a position, or comparing one axis against a threshold.


## Precision


The components of a double-precision vector come out as single-precision values. A world position far from the origin loses accuracy when taken apart this way, so keep such a position whole where its precision matters.
