# Length


![](../img/length.png)

### Description

Outputs the length of **A** - the distance from the origin to the point it describes, or the magnitude of the offset it represents.


To measure between two positions, subtract them and take the length, or use [Vec3 Distance](../../../../../code/plugins/scenariomanager/node_library/vector/distance.md), which does both in one node.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec3.png) | **A** | The vector to measure. |
| ![](../img/types/float.png) | **Result** | The length of the vector. |
