# Vec3 negate


![](../img/vec3_negate.png)

### Description

Reverses **A** by flipping the sign of each of its components, giving a vector of the same length pointing the opposite way.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec3.png) | **A** | The vector to reverse. |
| ![](../img/types/vec3.png) | **Result** | The reversed vector. |
