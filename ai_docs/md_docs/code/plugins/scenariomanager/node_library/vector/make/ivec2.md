# Make IVec2


![](../../img/make_ivec2.png)

### Description

Assembles an IVec2 from 2 whole numbers, one per component.


A component left unconnected takes the value typed into the node body, so a vector can be built with only the components that vary wired up.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/int.png) | **X** | The X component. |
| ![](../../img/types/int.png) | **Y** | The Y component. |
| ![](../../img/types/ivec2.png) | **Result** | The assembled vector. |
