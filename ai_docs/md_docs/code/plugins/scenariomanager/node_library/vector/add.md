# Vec3 Add


![](../img/vec3_add.png)

### Description

Adds the vectors **A** and **B** together, which moves a position by an offset or combines two offsets into one.


The [Add](../../../../../code/plugins/scenariomanager/node_library/math/add.md) node of the Math category performs the same addition and also accepts other vector types; this node states the Vec3 intent explicitly.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec3.png) | **A** | The first vector. |
| ![](../img/types/vec3.png) | **B** | The second vector. |
| ![](../img/types/vec3.png) | **Result** | The sum of the two vectors. |
