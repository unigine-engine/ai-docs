# Vec2 to Vec3


![](../../img/vec2_to_vec3.png)

### Description

Converts a Vec2 to a Vec3, carrying the existing components over and taking the new Z component from the **Z** input.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec2.png) | **Value** | The value to convert. |
| ![](../../img/types/float.png) | **Z** | The value of the new Z component. |
| ![](../../img/types/vec3.png) | **Result** | The converted value. |
