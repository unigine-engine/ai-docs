# Vec3 to Vec4


![](../../img/vec3_to_vec4.png)

### Description

Converts a Vec3 to a Vec4, carrying the existing components over and taking the new W component from the **W** input.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec3.png) | **Value** | The value to convert. |
| ![](../../img/types/float.png) | **W** | The value of the new W component. |
| ![](../../img/types/vec4.png) | **Result** | The converted value. |
