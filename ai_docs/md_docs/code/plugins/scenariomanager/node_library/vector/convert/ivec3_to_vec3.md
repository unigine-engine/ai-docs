# IVec3 to Vec3


![](../../img/ivec3_to_vec3.png)

### Description

Converts an IVec3 to a Vec3, turning each whole component into a floating-point one.


The conversion is exact for the range of whole numbers a float can represent.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec3.png) | **Value** | The value to convert. |
| ![](../../img/types/vec3.png) | **Result** | The converted value. |
