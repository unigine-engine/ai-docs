# Vec3 to DVec3


![](../../img/vec3_to_dvec3.png)

### Description

Converts a Vec3 to a DVec3, widening each component from single to double precision.


Widening is exact: the value is unchanged and simply gains the range to be combined with double-precision world coordinates.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec3.png) | **Value** | The value to convert. |
| ![](../../img/types/dvec3.png) | **Result** | The converted value. |
