# Vec4 to DVec4


![](../../img/vec4_to_dvec4.png)

### Description

Converts a Vec4 to a DVec4, widening each component from single to double precision.


Widening is exact: the value is unchanged and simply gains the range to be combined with double-precision world coordinates.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec4.png) | **Value** | The value to convert. |
| ![](../../img/types/dvec4.png) | **Result** | The converted value. |
