# IVec2 to Vec2


![](../../img/ivec2_to_vec2.png)

### Description

Converts an IVec2 to a Vec2, turning each whole component into a floating-point one.


The conversion is exact for the range of whole numbers a float can represent.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec2.png) | **Value** | The value to convert. |
| ![](../../img/types/vec2.png) | **Result** | The converted value. |
