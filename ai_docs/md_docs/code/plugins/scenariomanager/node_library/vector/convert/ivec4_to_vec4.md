# IVec4 to Vec4


![](../../img/ivec4_to_vec4.png)

### Description

Converts an IVec4 to a Vec4, turning each whole component into a floating-point one.


The conversion is exact for the range of whole numbers a float can represent.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/ivec4.png) | **Value** | The value to convert. |
| ![](../../img/types/vec4.png) | **Result** | The converted value. |
