# Vec3 to Vec2


![](../../img/vec3_to_vec2.png)

### Description

Converts a Vec3 to a Vec2 by keeping the X, Y components and discarding Z.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec3.png) | **Value** | The value to convert. |
| ![](../../img/types/vec2.png) | **Result** | The converted value. |
