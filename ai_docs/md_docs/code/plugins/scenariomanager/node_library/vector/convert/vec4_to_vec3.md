# Vec4 to Vec3


![](../../img/vec4_to_vec3.png)

### Description

Converts a Vec4 to a Vec3 by keeping the X, Y, Z components and discarding W.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec4.png) | **Value** | The value to convert. |
| ![](../../img/types/vec3.png) | **Result** | The converted value. |
