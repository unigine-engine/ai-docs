# Vec2 to DVec2


![](../../img/vec2_to_dvec2.png)

### Description

Converts a Vec2 to a DVec2, widening each component from single to double precision.


Widening is exact: the value is unchanged and simply gains the range to be combined with double-precision world coordinates.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../../img/types/vec2.png) | **Value** | The value to convert. |
| ![](../../img/types/dvec2.png) | **Result** | The converted value. |
