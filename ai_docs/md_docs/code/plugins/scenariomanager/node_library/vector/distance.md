# Vec3 Distance


![](../img/vec3_distance.png)

### Description

Outputs the distance between the points **A** and **B**.


Where the distance is only compared against another distance or a threshold, [Vec3 Distance2](../../../../../code/plugins/scenariomanager/node_library/vector/distance2.md) answers the same question without the square root, provided the threshold is squared to match.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/vec3.png) | **A** | The first point. |
| ![](../img/types/vec3.png) | **B** | The second point. |
| ![](../img/types/float.png) | **Result** | The distance between the two points. |
