# Frame Count


![](../img/frame_count.png)

### Description

Outputs the number of frames the script has been running for, counted from the frame it started in.


The counter belongs to the script rather than to the engine, so two scripts started at different moments report different values at the same instant.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/int.png) | **Frame** | The number of frames since the script started. |
