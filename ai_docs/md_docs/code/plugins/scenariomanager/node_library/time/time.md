# Game Time


![](../img/game_time.png)

### Description

Outputs the game time, in seconds. This is the engine-wide clock, shared by every script.


The value is useful for measuring how long something took: store it when an action starts and subtract it from the current reading later.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/float.png) | **Time** | The current game time, in seconds. |
