# Time Nodes


Nodes that read the current time and frame counters. They have no execution ports and can be read wherever a value is needed.


To act at regular intervals rather than read the time, use [On Timer](../../../../../code/plugins/scenariomanager/node_library/events/on_timer.md); to pause an execution chain, use [Delay](../../../../../code/plugins/scenariomanager/node_library/flow/delay.md).
