# Debug Nodes


Nodes that report what a graph is doing: writing to the log, printing on the screen, checking assumptions, and running console commands.


## Log Levels


[Log](../../../../../code/plugins/scenariomanager/node_library/debug/log.md) and [Format Log](../../../../../code/plugins/scenariomanager/node_library/debug/flog.md) write at one of three levels chosen by the **Level** parameter - message, warning or error. Entries are prefixed with SM Script, or with SM [tag] when a tag is set, which makes the output of a single graph easy to filter.
