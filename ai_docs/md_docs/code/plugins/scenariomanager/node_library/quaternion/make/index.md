# Make


Building a rotation from an axis and an angle in degrees, which is the direct way to express a single turn - a hatch about its hinge, or a turret about the vertical.


Where a rotation is authored as three separate angles instead, use [Euler to Quat](../../../../../../code/plugins/scenariomanager/node_library/quaternion/from_euler.md); to supply the four stored components directly, use the [Quat](../../../../../../code/plugins/scenariomanager/node_library/constants/quat.md) constant.
