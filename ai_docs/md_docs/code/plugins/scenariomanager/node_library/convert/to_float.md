# To Float


![](../img/to_float.png)

### Description

Converts a value to a floating-point number.


The input port is shown as Int, but a value of any type may be connected to it - a boolean gives 1 or 0, and a string is read as a number.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/int.png) | **Value** | The value to convert. |
| ![](../img/types/float.png) | **Result** | The value as a floating-point number. |
