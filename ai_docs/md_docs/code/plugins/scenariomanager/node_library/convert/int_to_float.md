# Int to Float


![](../img/int_to_float.png)

### Description

Converts an integer to a floating-point number.


This is the explicitly typed counterpart of [To Float](../../../../../code/plugins/scenariomanager/node_library/convert/to_float.md), which accepts a value of any type.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/int.png) | **Value** | The number to convert. |
| ![](../img/types/float.png) | **Result** | The number as a floating-point value. |
