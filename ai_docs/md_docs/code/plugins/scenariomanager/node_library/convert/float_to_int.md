# Float to Int


![](../img/float_to_int.png)

### Description

Converts a floating-point number to an integer, discarding the fractional part rather than rounding: 2.7 gives 2 and -2.7 gives -2.


This is the explicitly typed counterpart of [To Int](../../../../../code/plugins/scenariomanager/node_library/convert/to_int.md), which accepts a value of any type and converts it the same way.


#### Ports

| Name | Description |  |
|---|---|---|
| ![](../img/types/float.png) | **Value** | The number to convert. |
| ![](../img/types/int.png) | **Result** | The number with its fractional part discarded. |
